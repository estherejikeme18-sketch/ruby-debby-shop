# Ruby Debby Fashion Home — Shop Website

Fashion designer shop website (Lagos, Nigeria).
Dresses, bags, shoes & accessories. Prices in Naira.

## Live demo
After enabling GitHub Pages, site will be at:
`https://YOUR-USERNAME.github.io/ruby-debby-shop/`

## Features
- Hero + collection grid (12 products with photos)
- Category filter + live search + quick view
- Cart drawer (saved in localStorage)
- Checkout form + Order via WhatsApp
- Designer bio, testimonials, contact/footer

## Files
- `index.html` — all pages/sections
- `style.css` — styling
- `app.js` — products, cart, checkout logic
